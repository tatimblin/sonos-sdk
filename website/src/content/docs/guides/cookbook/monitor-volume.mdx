title: Monitor Volume
description: React to volume changes in real time.
---

## Fetch current volume

```rust
use sonos_sdk::prelude::*;

fn main() -> Result<(), SdkError> {
    let sonos = SonosSystem::new()?;
    let speaker = sonos.speaker("Kitchen").unwrap();

    let volume = speaker.volume.fetch()?;
    println!("Kitchen volume: {}%", volume);

    Ok(())
}
```

## Watch for volume changes

```rust
use sonos_sdk::prelude::*;

fn main() -> Result<(), SdkError> {
    let sonos = SonosSystem::new()?;
    let speaker = sonos.speaker("Kitchen").unwrap();

    // Subscribe to volume events
    let _watcher = speaker.volume.watch()?;

    // React to every change (physical knob, app, other controllers)
    for event in sonos.iter() {
        if event.property_key == "volume" {
            println!("Volume is now: {}%", event.value);
        }
    }

    Ok(())
}
```

## Set volume

```rust
// Absolute volume (0-100)
speaker.volume.set(50)?;

// Read back to confirm
let confirmed = speaker.volume.fetch()?;
assert_eq!(confirmed, 50);
```

## Monitor multiple speakers

```rust
use sonos_sdk::prelude::*;

fn main() -> Result<(), SdkError> {
    let sonos = SonosSystem::new()?;

    // Watch volume on all speakers
    for speaker in sonos.speakers() {
        speaker.volume.watch()?;
    }

    // Events from all speakers arrive here
    for event in sonos.iter() {
        if event.property_key == "volume" {
            println!("{}: {}%", event.speaker_id, event.value);
        }
    }

    Ok(())
}
```

## Related properties

Volume often changes alongside these:

```rust
let _mute = speaker.mute.watch()?;
let _loudness = speaker.loudness.watch()?;

for event in sonos.iter() {
    match event.property_key.as_str() {
        "volume" => println!("Volume: {}", event.value),
        "mute" => println!("Mute: {}", event.value),
        "loudness" => println!("Loudness: {}", event.value),
        _ => {}
    }
}
```
