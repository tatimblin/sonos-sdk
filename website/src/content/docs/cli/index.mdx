## Install in seconds

<Tabs>
  <TabItem label="Homebrew">
    ```bash
    brew install tatimblin/tap/sonos-cli
    ```
  </TabItem>
  <TabItem label="Cargo">
    ```bash
    cargo install sonos-cli
    ```
  </TabItem>
  <TabItem label="Binary">
    Pre-built binaries for macOS, Linux, and Windows are available on the [Releases](https://github.com/tatimblin/sonos-cli/releases) page.
  </TabItem>
</Tabs>

## Why Sonos CLI?

<CardGrid>
  <Card title="Zero config" icon="rocket">
    Auto-discovers speakers on your network. Just install and run.
  </Card>
  <Card title="Group-aware" icon="list-format">
    Target individual speakers or entire groups with --speaker and --group flags.
  </Card>
  <Card title="Built on Sonos SDK" icon="puzzle">
    Same reliable Rust SDK under the hood. Consistent behavior, no surprises.
  </Card>
  <Card title="Scriptable" icon="setting">
    Compose with shell scripts, cron jobs, and automation tools.
  </Card>
</CardGrid>

## Quick taste

```bash
sonos speakers          # Discover your speakers
sonos status            # See what's playing
sonos volume 50 --group "Living Room"
sonos next              # Skip track
```
